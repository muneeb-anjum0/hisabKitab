# Security policy

HisabKitab protects each ledger with authenticated Firebase rules and keeps Android
release signing material outside the repository.

If you discover a security issue, please do not publish account data, credentials, or
an exploit in a public issue. Use GitHub private vulnerability reporting when it is
available for this repository, or contact the maintainer through the GitHub profile.

Include a clear reproduction path, the affected platform/version, and the potential
impact. Reports are reviewed for supported stable releases.
